设置

病毒库、推理服务、运行时与证据存储配置。

病毒库与检测
内置规则库随程序发布，覆盖勒索、窃密、挖矿、远控、注入、持久化、横移、脚本投放等已知攻击族谱特征；可导入哈希清单（MD5/SHA1/SHA256，txt/csv/json）与外置 YARA 规则。检测只读取沙箱内的样本副本，样本不会被执行，主系统不被影响。
CVE 漏洞库与检测
内置 CVE 库取自 NVD（nvd.nist.gov），覆盖 OpenSSL、zlib、libpng、libxml2、SQLite、curl、OpenSSH、Log4j、Struts、Spring、Tomcat、WebLogic、fastjson、jQuery 等常见第三方组件；检测先识别组件版本（版本资源、导入表、字符串 banner），再按版本区间与特征做匹配。可导入 CSV/JSON（字段：cveId/component/kind/affected/min/max/cvss/severity/desc/fix），或在线同步两个来源：NVD（按组件关键词精确检索）、CNNVD 国家信息安全漏洞库 www.cnnvd.org.cn（厂商/产品维度检索，字典大小写敏感，程序会自动尝试大小写变体；未收录的词回退为最新漏洞本地筛选，关键词留空则直接拉取最新漏洞）。CNNVD 条目按组件名匹配、附带详情链接与 CNNVD 定级，版本仍需人工核对；同步结果带来源标记并可从“查看 CVE 条目”中核对，“清空导入”可整体撤销外部同步与导入内容。检测只读取沙箱内的样本副本，样本不会被执行。

关于

REA Studio 是面向本机样本的离线逆向分析工具：拖入本机可执行文件、程序集或制品，即可完成类型识别、静态解析、网络行为还原、站点抓取与 AI 解读，并一键导出 Markdown / PDF 报告。全部分析与推理均在本机完成，样本与结论不出本机、不上传云端。
